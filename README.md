실행하는 법 : npm run dev  

폴더구조설명  
url 주소 만드는 구조  
src/app 에 하위폴더로 만들면 url주소가 생김  
예 - app폴더 안에 question 폴더 생성 -->  http://localhost:3000/question 이렇게 만들어짐  

페이지설명  
자유(free) - 자유게시판  
질문(question) - 질문게시판  
기록(history) - 게임기록게시판  
정보(games) - 게임정보 게시판  
뉴스(news) - 뉴스&공지 게시판  
마페(mypage) - 마이페이지  
로그인(login) - 로그인화면  
회원가입(signup) - 회원가입 화면
